GIL Bottleneck (current)
PyO3 embeds CPython in the Rust process. Python::with_gil() acquires the Global Interpreter Lock. Only ONE Python execution can run at a time across ALL sessions. spawn_blocking prevents the Tokio async runtime from stalling, but Python calls are serialized. This is why we're moving to subprocess model — each session gets its own process with its own GIL.

09 — prior art & research papers
LLM-in-Sandbox (arxiv:2601.16206, Jan 2026)
Closest academic validation of our approach.
Lightweight Python + numpy/scipy only. Model installs its own tools on-the-fly.
Key finding: agents spontaneously use filesystem for context management and install packages dynamically.
Implication: consider relaxing network block for pro-tier (allow pip install from whitelist).
RedCodeAgent (ICLR 2026)
Automated red-teaming of code agents. Tested OpenCodeInterpreter, MetaGPT, Cursor, Codeium.
Found real vulnerabilities across all tested agents.
Implication: import blocklist alone is insufficient. Need defense in depth: process isolation + seccomp + filesystem jail + rlimits.
AgentSpec (ICSE '26, April 2026)
Customizable runtime enforcement policies for safe LLM agents.
Implication: expose policy language so enterprise customers can define their own sandbox rules.
Securing AI Agent Execution (arxiv:2510.21236)
Threat model: the workload itself is untrusted (LLM-generated code may be adversarial via prompt injection).
Implication: assume ALL submitted code is potentially malicious, even from "trusted" agents.

what the research changes
Security must be layered
RedCodeAgent proves single-layer defense fails. Our target stack:

L1: Process isolation (separate PID ns) L2: Syscall filter (seccomp-bpf) L3: Filesystem jail (chroot/bind) L4: Resource limits (cgroups/rlimit) L5: Import blocklist (Python-level)
Where our moat lives
The sandbox layer is table stakes — everyone has one.

Phase 1: ML-aware (pre-loaded libraries) = small edge
Phase 2: Distribution (OpenClaw skill, agent-native API) = market timing
Phase 3: greed-torch + wgpu = real moat. Vendor-agnostic GPU compute for agents. Nobody else is building this.
